# WSAA-coursework

## Overview
This repository contains my coursework for the Web Services and Applications (WSAA) module. It is used to store and organise the work I completed throughout the duration of the course.

The repository is divided into two main sections:
- Assignments – Weekly tasks that are completed as part of the continuous assessment.
- Labs – Practice work and exercises completed during labs (not graded).

## Assignments
The assignments folder contains weekly tasks that form part of the module’s assessment.

Contents:
- CardDraw.py
- CSO.ipynb
- Github.ipynb

The assignment folder also includes two supporting files, cso.json and text.txt, which are used to provide data and ensure the programs run correctly.
